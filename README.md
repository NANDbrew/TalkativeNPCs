# Talkative NPCs
Gives NPCs a speech bubble.
- Speech bubble is shown and hidden as needed.
- NPCs have a 30% chance to greet you with a random blurb. They'll also complain and call you names if you throw things at them. 
- An extremely basic disposition system which goes down whenever they're hit, and when it goes low enough it will start to affect your regional reputation.
- Very basic patching of tavern rumor characters. Hit them enough and they'll demand more drinks to raise their disposition before they're willing to share rumors.

**Settings**
- Patch rumor dude
  - Integrate tavern rumor NPCs with the mod's disposition system.
  - Requires a reload if toggled from the Mod Configuration Menu.
